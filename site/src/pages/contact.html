Pilots, questions and product feedback

Open a GitHub issue for a non-sensitive product question, bug or feature request. Include the page, what you expected and what happened. Issues are public: leave out customer data, credentials, private keys and recovery phrases.

Report a security problem privately

Use GitHub's private vulnerability report to send security findings to the maintainers without publishing a public issue. A GitHub account is required. Never include a live key or recovery phrase in a report.
