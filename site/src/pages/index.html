Software updates for device fleets, with release authority you can verify.

SuiFleet deploys software and configuration to Linux devices. Release authority, deployment targets and signed device results are recorded on a public ledger, confidential artifacts are encrypted for the devices allowed to read them, and there is no SuiFleet application server between you and your fleet.

Verifiable release authority

Only the wallets you authorize can publish a version or start a deployment. Anyone you share a fleet with can check who released what, to which devices, and when.

Tamper-evident update records

Devices sign their own results. Signatures let you verify the reporting identity and detect altered results. A report is the device’s claim, not independent proof of healthy hardware.

Encrypted delivery

With confidential delivery, artifacts are encrypted in your browser before upload. Only the accounts, devices and groups named in the access policy can decrypt them.

Staged rollouts

Release to a first wave, check signed post-update health, then widen. A rollout stops when failures cross the threshold you set.

No lock-in, no servers

The console is a static web app. Devices talk to public Sui and Walrus networks. The client and contracts are MIT-licensed open source.

Priced from measured usage

A per-device price with network fees included, built from the cost of the transactions and storage a fleet uses. See pricing.

From first device to staged rollout

  1. Sign in with a Sui wallet or a Google account, and fund the fleet's network budget.
  2. Register devices one at a time, or enroll a manufacturing batch that claims itself on first boot.
  3. Publish a version: upload the artifact and its recipe, encrypted, to Walrus.
  4. Deploy it to a device group, or run a staged rollout gated on device health.

Built for embedded Linux teams

SuiFleet's client is a small Rust daemon for Linux devices, packaged for Yocto, Debian-style systems, macOS and Windows test hosts. It verifies every artifact against the digest you published, runs the lifecycle commands you configured and reports the result. Your platform's updater (for example SWUpdate or RAUC) stays in charge of partitions, reboots and firmware rollback.

Teams moving from AWS IoT Greengrass can map their deployment model onto SuiFleet; full Greengrass recipe and API compatibility is on the roadmap, not a current claim. Read the documentation or the security and custody notes.

Status. SuiFleet runs on Sui testnet today. Mainnet service, production key providers and hardware-signed devices are not yet launched. Do not use the preview for production devices.
