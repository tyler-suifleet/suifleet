# Detailed illustration set

Generated with the built-in `image_gen` tool for the sample film. These are
illustrative product concepts, not photographs of supplied hardware or screenshots
of the application. The approved visual brief is in [prompts.json](prompts.json),
including the exact prompt for each asset and the transparency request.

- `workstation.png`: detailed laptop/approval-phone workstation.
- `gateway.png`: industrial edge gateway with ports, cooling fins and display.
- `storage.png`: conceptual software-file storage trays and cartridges.

All three originals are 1254×1254 RGBA PNGs. Their original bytes and alpha channel
are preserved; no bitmap editing or background substitution was used. Remotion
positions/scales them and animates separate interface overlays and transfers.
The shared palette is graphite/navy, brushed aluminum, cobalt and mint. Labels,
release versions, captions and verification states are rendered separately so
text and animation remain editable and accurate.
