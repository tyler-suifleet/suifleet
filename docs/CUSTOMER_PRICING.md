# Understand pricing and network estimates

Use the public pricing information for planning and obtain confirmed terms before purchasing.

## Prerequisites

Know device count, release sizes/frequency, health/log cadence, retention and the intended network. Distinguish a proposed subscription from actual Sui/Walrus resource charges.

## Steps

1. Review the [pricing page](https://suifleet.io/pricing/) and request a written quote for the required availability and service scope.
2. Enter realistic workload assumptions in **Fleet settings** and **Network budget**. Compare both per-device and fleet totals.
3. Confirm deposit amount, network and actual wallet transaction fee before approving. A settings save does not add funds or buy a subscription.
4. Monitor actual balance, storage expiry and usage; revisit assumptions as fleet behavior changes.

## Expected result

You have a planning estimate and separately confirmed order terms. Only successful on-chain execution establishes that a network deposit occurred.

## Recovery and limits

If live prices cannot be read, retry or obtain a quote instead of assuming zero cost. Network prices and provider requirements can change. Estimates are not a guaranteed bill, fixed fee or permission to purchase services. Final provider/account setup and production acceptance remain separate.
