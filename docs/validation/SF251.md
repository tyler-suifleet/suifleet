legacy customer's migration fallback; no new customer needs a static locator.

physical clients still need a controlled v4 connection-settings rollout.

## Reproduction and recovery

Public identifiers/configuration are in `profiles/seal-testnet/`, including
`reporting-release.json`. Private signing state and fsynced operation/native
journals remain under `~/.local/state/suifleet/sf251-reporting/`, outside Git.
Never dump that directory or lease/claim files into an issue.

For a genuinely new authorized release, with the shared mutation lease already
asserted and exported privately as `SUIFLEET_TESTNET_LOCK_TOKEN`:

```bash
python3 scripts/live_evaluation_reporting.py --wallet /explicit/agent/client-host.yaml \
  --runtime /private/new-run --compiler /pinned/1.81.1/sui \
  --network-cli /pinned/1.83.0/sui
python3 scripts/live_evaluation_reporting.py --wallet /explicit/agent/client-host.yaml \
  --runtime /private/new-run --compiler /pinned/1.81.1/sui \
  --network-cli /pinned/1.83.0/sui --accept-release
```

Do **not** rerun publication for this existing release. An existing journal stops
release replay. Acceptance continuation inherits prior charges and rejects unknown
or already-started work. An interruption requires explicit digest/effects and gas
reconciliation, not deletion of a journal or a replacement allowance. The native
signer refuses a second recorded transaction even after restart.
